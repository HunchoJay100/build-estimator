# Build Cost Estimator — Modern Development

Single-file lead-magnet calculator for Flynn Development / Modern Development custom homes.
Live at **build.moderndevelopment.co** (GitHub Pages + custom subdomain).

- `index.html` — the calculator (Modern Dev dark/gold, Fraunces + Manrope)
- Lead modal POSTs to a GoHighLevel inbound webhook (`GHL_WEBHOOK_URL` const in index.html)
- Cost model is editable CONFIG at top of the script block, derived from real 2026 Putnam County projects
